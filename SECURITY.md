# Security

If you've found a security problem in anything Itrium makes, please tell us privately rather
than in a public issue, so it can be fixed before anyone else knows about it.

- **On GitHub:** open the repository's **Security** tab and click **Report a vulnerability**.
- **By email:** [security@itrium.id](mailto:security@itrium.id).

Tell us which application and version is affected, what someone could do with the problem, and
how to reproduce it. We aim to reply within a week, we'll keep you posted while we fix it, and
we'll credit you in the release notes if you'd like.

Only the latest release of each application gets security fixes. Our tools are free, so we
can't offer bounties.
